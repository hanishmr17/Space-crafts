About Satellites

A satellite is an object that orbits a larger body. Satellites can be:

  • Natural: like the Moon orbiting Earth
  • Artificial: built by humans, like communication or weather satellites

Steps in a basic satellite mission

  1. Design and build the satellite
  2. Test it on the ground
  3. Launch it on a rocket
  4. Deploy it into orbit
  5. Receive data from it (telemetry)
